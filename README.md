## 🚀 How to Publish to GitHub Pages

Your portfolio is 100% static and self-contained (HTML, CSS, JS, and local assets). It runs out-of-the-box on **GitHub Pages** without requiring any build step or compilation.

1. Go to your repository on GitHub: [github.com/satyam0404/Portfolio](https://github.com/satyam0404/Portfolio)
2. Click on **Settings** → **Pages** (in the left sidebar).
3. Under **Build and deployment**:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` and folder `/ (root)`
4. Click **Save**.
5. Your website will be live in 1–2 minutes at:
   - **`https://satyam0404.github.io/Portfolio/`**

## 💻 Running & Testing Locally

You can test the website locally at any time:

- **Option A**: Double-click `preview.bat` in this folder.
- **Option B**: Run via PowerShell/Terminal:
  ```bash
  python -m http.server 5000
  # Open in browser: http://localhost:5000/
  ```

To push updates to GitHub in 1 click:
- Double-click `sync.bat` in this folder!
